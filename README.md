# JobGenie-Rag-Service-agent
RAG service for resume processing using LangChain, Google Gemini Embeddings, and ChromaDB for semantic retrieval and AI-powered career assistance.

## Week 2 Progress

### Objective
Implemented a Retrieval-Augmented Generation (RAG) service for processing resume documents.

### Features Completed

- PDF Loading using PyPDFLoader
- Text Chunking using RecursiveCharacterTextSplitter
- Gemini Embeddings Integration
- ChromaDB Vector Store Setup
- Retriever Creation

### Workflow

Resume PDF
↓
Document Loader
↓
Text Splitter
↓
Embeddings
↓
ChromaDB
↓
Retriever

### Technologies Used

- Python
- LangChain
- Google Gemini
- ChromaDB
- PyPDFLoader

### Status

RAG Service Implemented and Under Testing.
